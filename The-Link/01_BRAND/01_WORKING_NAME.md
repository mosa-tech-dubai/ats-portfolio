# Working Name: The Link

## The Name

**The Link.**

## Why This Name

The name was selected because it represents the central idea of the entire project:

- We connect people with people.
- We connect people with expertise.
- We connect hidden experts with audiences.
- We connect questions with answers.
- We connect customers with specialists, naturally, without a hard sell.
- We connect communities.

## Why It Survives the Automotive Starting Point

The name does not reference cars, garages, mechanics, or any single vertical. It describes the *function* of the project — connection — which is exactly what stays true whether the guest is a BMW specialist this year or a watchmaker or aerospace engineer three years from now. This is a deliberate naming choice, made because the project is explicitly designed to outgrow automotive (see `00_PROJECT_BIBLE/01_PROJECT_VISION.md`).

## Naming Space for Extensions

Not committed, not scheduled — documented only as naming space the brand could grow into once/if the need arises:

- The Link Podcast
- The Link Live
- The Link Shorts
- The Link Community
- The Link Events

These sub-brand names should not be treated as a locked roadmap. They exist so that future formats have an obvious, consistent naming pattern to slot into.

## Status of This Decision

The Link is the **current preferred working name**, used across all documents, scripts, and planning in this project unless explicitly noted otherwise. It is not yet the final, locked brand name. Four alternatives remain actively documented in `02_NAME_ALTERNATIVES.md` and must not be deleted or treated as discarded.

**Decision trigger:** the name should be finalized before any spend on visual identity, merchandise, domain registration, or legal/trademark work, and no later than the pilot review (`04_PILOT/06_PILOT_REVIEW.md`).
