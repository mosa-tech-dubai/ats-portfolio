# Visual Identity

No visual identity has been finalized. This file documents the constraints the identity must satisfy once it's designed, and the checklist of assets that will eventually need to exist. Treat every item below as open until a specific version is approved and this file is updated to `STATUS: Approved`.

## What the Identity Must Communicate

Discovery + Expertise + Human Stories + Modern Media.

## The One Hard Constraint Already Decided

**The identity must not look like a generic car-repair or automotive-review channel.** Because automotive is the starting niche but not the ceiling (see `00_PROJECT_BIBLE/01_PROJECT_VISION.md`), the visual language should read as "documentary media brand," not "garage brand." Avoid literal automotive iconography (wrenches, gears, checkered flags) as primary brand marks — these can appear in automotive-specific episode treatments, but not in the core logo/brand system.

## Open Items — `TO BE DEVELOPED`

- **Logo** — wordmark, symbol, or combination; must work at favicon size and on a thumbnail.
- **Typography** — a primary display face and a body/caption face, legible in video captions at small sizes.
- **Color system** — primary palette plus a flexible secondary/accent system that can shift per content vertical without breaking brand recognition.
- **Motion identity** — logo animation, transition style, lower-third animation style.
- **Intro** — target length under 5 seconds once designed; should not delay the cold open (see `03_EPISODE_SYSTEM/05_COLD_OPEN.md`).
- **Outro** — end-card system carrying CTA + guest contact info (see `03_EPISODE_SYSTEM/06_OUTRO_AND_CTA.md`).
- **Lower thirds** — name/title/business treatment for guests.
- **Subtitles** — caption styling standard (see `06_POST_PRODUCTION/03_SUBTITLES.md` for platform requirements this must satisfy).
- **Thumbnails** — a repeatable, testable thumbnail system (see `06_POST_PRODUCTION/04_THUMBNAILS.md`).
- **Episode covers** — cover art system for the long-form catalogue.
- **Social templates** — Reels/Shorts/TikTok cover and caption-card templates per `02_CONTENT_STRATEGY/04_PLATFORM_STRATEGY.md`.
- **Studio/location visual rules** — how the brand shows up physically on location (mic flags, clapperboard, any on-site signage) without turning the shoot into a production circus.
- **Photography style** — still-image direction for behind-the-scenes and marketing stills.
- **Camera language** — shot grammar/movement style, cross-referenced with `05_PRODUCTION/04_CAMERA.md`.

## Recommended Sequencing

Visual identity work should follow, not precede, the naming decision (`01_WORKING_NAME.md` / `02_NAME_ALTERNATIVES.md`) and the pilot (`04_PILOT/`), since the pilot is explicitly meant to stress-test tone and format before locking anything visual. Building a full identity before the name and pilot are settled risks throwaway work.
