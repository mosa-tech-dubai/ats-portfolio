# Script Prompts

Prompt patterns for scripts, interview questions, cold opens, and outros. Read `00_AI_READ_FIRST.md` first.

## Full Episode Question Plan

> "Using `03_EPISODE_SYSTEM/03_QUESTION_BANK.md` and `04_PILOT/03_PILOT_QUESTION_PLAN.md` as a model, build a guest-specific question plan for a [specialty] specialist named [guest] at [location type]. Organize it by Episode Structure section (`03_EPISODE_SYSTEM/01_EPISODE_STRUCTURE.md`). Do not treat this as a script to follow rigidly — note where the interviewer should let the guest lead, per `02_INTERVIEW_FRAMEWORK.md`."

## Cold Open Draft

> "Given this raw highlight moment from a shoot: [paste highlight/quote]. Draft 3 cold open variants following `03_EPISODE_SYSTEM/05_COLD_OPEN.md`. Do not paraphrase the guest's claim into something stronger than what they actually said."

## Outro / End Card Copy

> "Draft outro copy for this episode following `03_EPISODE_SYSTEM/06_OUTRO_AND_CTA.md`. The final-value takeaway is: [X]. The community question is: [Y]. Keep guest business information out of the narrated copy — that belongs in the end card/description only."

## Video Description / Caption

> "Write a YouTube description for this episode using `01_BRAND/04_TONE_OF_VOICE.md`. Include chapters, the community question as text, and the guest's business information as reference, not narration. Check it against the Ad Test in `00_PROJECT_BIBLE/04_DECISION_PRINCIPLES.md` before finalizing."

## Guardrail for All Script Work

Before returning a script, the AI should self-check: does any line read as "go visit this business" rather than letting the viewer discover the specialist naturally? If yes, revise before presenting the draft.
