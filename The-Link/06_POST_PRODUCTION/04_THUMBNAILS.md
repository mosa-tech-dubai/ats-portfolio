# Thumbnails

No thumbnail system has been designed or tested yet. This file documents the constraints it must satisfy once designed — see `01_BRAND/06_VISUAL_IDENTITY.md`, which owns the visual system this depends on.

## Constraints Any Thumbnail System Must Satisfy

- Must not look like a generic automotive-repair channel thumbnail (same constraint as the broader visual identity — see `01_BRAND/06_VISUAL_IDENTITY.md`).
- Must communicate curiosity/discovery rather than a sales pitch — avoid "before/after" or "you won't believe" clickbait framing that oversells relative to the actual content (this would fail the Value Test in `00_PROJECT_BIBLE/04_DECISION_PRINCIPLES.md`).
- Should feature the guest's face/expression where possible — human faces are core to the brand's human-story positioning (`00_PROJECT_BIBLE/03_CORE_PHILOSOPHY.md`).
- Should be a repeatable, testable template system (consistent logo placement, text treatment) rather than a one-off design per episode, once the visual identity is locked.

## Pilot Role

The pilot (`04_PILOT/`) should test at least a couple of thumbnail directions and record what performed better in `04_PILOT/06_PILOT_REVIEW.md`, even before a full visual identity exists — early signal here is valuable and shouldn't wait.

## Next Step

Design a template system once `01_BRAND/06_VISUAL_IDENTITY.md` has an approved logo/type/color direction.
