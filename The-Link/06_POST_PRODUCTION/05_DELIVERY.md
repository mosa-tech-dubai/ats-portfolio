# Delivery

Technical delivery specs (export codecs/resolutions per platform, file naming for delivered assets, archival storage plan) have not yet been defined.

## Principles to Follow Until a Full Spec Exists

- Deliver each platform's asset at that platform's recommended native resolution/aspect ratio/codec rather than one-size-fits-all exports, consistent with the adaptation principle in `02_CONTENT_STRATEGY/04_PLATFORM_STRATEGY.md`.
- Keep a master, uncompressed (or high-bitrate) archival export of the full long-form edit separate from platform-compressed delivery files — the long-form master is the source for all future short-form extraction (`02_CONTENT_STRATEGY/05_CONTENT_REPURPOSING.md`), including clips pulled long after initial release.
- File naming for delivered/archived assets should follow whatever convention is defined in `10_OPERATIONS/04_FILE_NAMING.md` once that document is developed — don't improvise a competing convention here.
