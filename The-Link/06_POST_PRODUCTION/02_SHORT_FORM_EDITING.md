# Short-Form Editing

## Start From the Highlight Log

Short-form editing starts from the highlight log captured during filming (`03_EPISODE_SYSTEM/04_HIGHLIGHT_SYSTEM.md`), not from a cold rewatch of the full raw footage. This is what makes the content repurposing system (`02_CONTENT_STRATEGY/05_CONTENT_REPURPOSING.md`) actually fast enough to sustain a publishing cadence.

## General Short-Form Principles

- Each clip should stand completely on its own — a viewer with zero context for the full episode should still understand and get value from it.
- Lead with the hook in the first 1–3 seconds; don't build up to the interesting part.
- Keep on-screen captions/subtitles on by default — see `03_SUBTITLES.md` — since most short-form viewing happens sound-off.
- Match pacing and framing conventions to the destination platform (`02_CONTENT_STRATEGY/04_PLATFORM_STRATEGY.md`) without changing the underlying tone.

## Mapping Highlight Categories to Clip Types

| Highlight category | Typical clip type |
|---|---|
| Educational | "Did you know?" clip |
| Surprising | Hook-driven short with the surprise as the payoff |
| Funny | Standalone humor clip |
| Emotional | Personality/human-interest clip |
| Controversial-but-responsible | Discussion-bait clip (pair with a community question) |
| Practical tip | Direct tip clip, often text-overlay heavy |
| Expert statement | Quote card / quote clip |
| "You won't believe this" | Twist-driven short |
| Myth/fact | Myth vs. fact clip |
| Customer/expensive mistake | Problem/solution clip |
| Unusual case | Story clip |

## Never

- Never build a short-form clip that implies a different claim than the guest actually made, even for a stronger hook.
- Never strip a clip of enough context that it becomes misleading about the guest, their business, or the advice given.
