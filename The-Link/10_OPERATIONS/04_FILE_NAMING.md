# File Naming

No formal file naming or asset-management convention has been adopted yet. This file documents the goal and constraints so that whatever convention is adopted stays consistent.

## Goals for a Future Convention

- Every raw footage, edited asset, and delivered file should be traceable back to its episode/guest and shoot date without opening the file.
- The convention should stay stable as production scales — avoid anything that only works for the pilot's single-guest, single-location simplicity.
- Should support the content repurposing model directly: it must be easy to find every short-form asset that came from a given long-form shoot (`02_CONTENT_STRATEGY/05_CONTENT_REPURPOSING.md`).
- Should align with archival/delivery practices once `06_POST_PRODUCTION/05_DELIVERY.md` is developed.

## Next Step

Adopt a real convention (e.g., `[EpisodeNumber]_[GuestOrShortName]_[Date]_[AssetType]_[Version]`) once the pilot's actual asset volume and folder structure needs are known — don't lock a scheme before real production data exists to validate it against.
