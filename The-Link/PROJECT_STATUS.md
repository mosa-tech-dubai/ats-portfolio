# Project Status

The living snapshot of what's decided, in progress, open, and future for The Link. Update this file whenever a status changes elsewhere in the project — it should always be trustworthy as the single place to check "where do things actually stand."

## DECIDED

- The project is bigger than a podcast — it's a media platform and community.
- The project is about real-world expertise and connection, not service advertising.
- The initial content focus is automotive, used as a proving ground, not a permanent ceiling.
- The format happens primarily at the guest's actual workplace/location.
- Content must be useful and entertaining — value before views.
- Marketing is indirect and content-first; episodes must never read as advertisements.
- Community participation is a core mechanic, not an afterthought.
- Long-form content is designed from the outset to generate short-form content (one shoot → a content ecosystem).
- Live interaction is a planned future layer of the ecosystem, not a launch requirement.
- The brand must scale beyond automotive into other expertise fields.
- The current working brand name is "The Link."
- Alternative names (Uncovered, Insight, Hidden Experts, Beyond) remain documented and must not be deleted.
- The pilot is a test lab for the entire system, not simply "Episode 1."
- Core philosophy: Experience + Story + Discovery + Connection + Value.
- Any monetization must remain compatible with audience trust.
