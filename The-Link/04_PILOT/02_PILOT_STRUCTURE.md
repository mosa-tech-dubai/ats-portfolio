# Pilot Structure

## Baseline

The pilot follows `03_EPISODE_SYSTEM/01_EPISODE_STRUCTURE.md` exactly, section by section (Cold Open → Fast Intro → Who Is This Person? → The Place → Expertise/Value → Real Stories → Practical Demonstration → Human/Light Moment → Final Value → Community Question). The point of the pilot is to test that structure against reality, so it should not be redesigned in advance — deviations should be *observed and noted*, not pre-planned around.

## Pilot-Specific Additions

Because this is a test lab, the pilot carries extra instrumentation the routine production workflow won't always need:

- A highlight log kept live during filming (`03_EPISODE_SYSTEM/04_HIGHLIGHT_SYSTEM.md`), reviewed specifically afterward for how well the system worked, not just for its content.
- A running production diary — what took longer than expected, what required a workaround, what equipment or setup failed.
- Explicit before/after notes on brand tone: does the guest and location feel true to `01_BRAND/04_TONE_OF_VOICE.md`, or does the episode drift toward either generic car-repair content or generic corporate-interview content?

## Target Length

Same as standard: approximately 25–40 minutes for the long-form cut. If the pilot naturally runs shorter or longer, note why in `06_PILOT_REVIEW.md` rather than forcing it to fit.

## What Happens After Filming

1. Full edit produced following `06_POST_PRODUCTION/01_EDITING_GUIDELINES.md`.
2. Short-form extraction attempted following `06_POST_PRODUCTION/02_SHORT_FORM_EDITING.md` and `05_PILOT_CONTENT_EXTRACTION.md`.
3. Release across the platforms in `02_CONTENT_STRATEGY/04_PLATFORM_STRATEGY.md` that are ready to use.
4. Formal review per `06_PILOT_REVIEW.md` once initial audience data is in.
