# Pilot Review

This document does not yet contain a review — the pilot has not been shot. It exists now to define the review framework, so that when the pilot is complete, analysis is structured and comparable rather than ad hoc.

## What the Review Must Answer

One section per objective from `01_PILOT_OBJECTIVES.md`:

- **Brand name** — did "The Link" feel right on camera, in the title, and in casual conversation about the project? Any signal favoring one of the alternatives in `01_BRAND/02_NAME_ALTERNATIVES.md`?
- **Brand tone** — did the finished episode match `01_BRAND/04_TONE_OF_VOICE.md`, or drift toward generic car-repair content or generic corporate interview content?
- **Episode structure** — which sections of `03_EPISODE_SYSTEM/01_EPISODE_STRUCTURE.md` worked as written, and which needed to flex or reorder in practice?
- **Interview framework** — did the Interviewer Rule (letting the guest talk) actually get followed under real filming pressure? Where did it break down?
- **Filming style, movement, location storytelling** — what worked, what needs a different approach next time?
- **Guest interaction** — did the guest seem comfortable and understood, or exposed/misrepresented?
- **Audio and camera setup** — technical issues encountered, fixes needed before the next shoot.
- **Cold open, intro, outro, thumbnail** — did they perform as intended (see `03_EPISODE_SYSTEM/05_COLD_OPEN.md`, `06_OUTRO_AND_CTA.md`)?
- **Short-form extraction** — results against `05_PILOT_CONTENT_EXTRACTION.md`'s target list.
- **Audience reaction, comments, retention** — actual data, once available, compared against the Value Test and Community goals (`00_PROJECT_BIBLE/04_DECISION_PRINCIPLES.md`, `07_COMMUNITY/`).
- **Workflow and editing process** — realistic time-per-output data to replace assumptions in `10_OPERATIONS/01_WORKFLOWS.md`.

## Decisions the Pilot Should Unblock

- Final brand name (`01_BRAND/02_NAME_ALTERNATIVES.md`)
- Taglines (`01_BRAND/05_TAGLINES.md`)
- Visual identity direction (`01_BRAND/06_VISUAL_IDENTITY.md`)
- Realistic publishing cadence (`02_CONTENT_STRATEGY/04_PLATFORM_STRATEGY.md`)
- Whether the current episode structure needs revision before scaling to more guests
