# ats-portfolio

This repository holds two separate things. Don't confuse them.

## 1. `index.html` — the live ATS business site

A single-file static site for ATS (Automotive Tech Solutions) — advanced diagnostics, key programming, ECU bench work, and ADAS calibration, based in Saqr Industrial Area (Sagaa), Sharjah, UAE. Kept at the repo root so it can be served directly (e.g. GitHub Pages from root).

## 2. `The-Link/` — The Link project operating system

Full documentation and working system for **The Link**, a separate media/community project (podcast-led, expertise-focused) currently using ATS as its pilot guest. This is not the ATS site's content — it's the project bible, brand, content strategy, episode system, pilot pre-production, production/post-production guidelines, community, growth, business, operations, and AI workspace docs for building that media brand.

Start here:
- `The-Link/00_PROJECT_BIBLE/00_READ_ME_FIRST.md` — read this before any strategic or creative work on The Link.
- `The-Link/PROJECT_STATUS.md` — the living snapshot of what's decided, in progress, open, and future.

## `.claude/agents/`

Claude Code subagent definitions used while working in this repo (currently: `videographer.md`, for generating previs/B-roll video for The Link's pilot).
